Privacy

Everything you add stays on this device. Inkcadence has no account, no analytics, and no server that receives your pages.

Photos

A letter sheet or an old page is read in the browser so the letters can be cut out. The photo is not uploaded. The saved hand keeps the letter images, not the photo.

Hands

A hand is stored in this browser, in IndexedDB. Closing the site does not send it anywhere. If this browser cannot store data, the hand lasts only until you close the tab, and the app says so.

Export

A .inkpack file is a copy of the hand that you download yourself. It does not contain the photos. PNG and PDF files are also created on this device. They include an AI-assisted note in the file.

What this site loads

The first visit downloads the app from GitHub Pages. After that, writing does not need a network. This site does not embed a third-party tracker.
