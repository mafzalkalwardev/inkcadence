How it works

Five steps, all in the browser. The first two are required. Old pages are optional.

1

Attest

Tick that this is your handwriting. Only use writing you made yourself.

2

Letter sheet

Print the sheet, write one character in each box, and photograph both pages. With no printer, copy the five lines onto paper and photograph that page.

3

Old pages

Add up to eight pages you already wrote. They teach the pen, the slant, and headings. This step can be skipped.

4

Review

Check the letters. Generated letters are marked. Save the hand.

5

Write

Type your words. Start a line with # for a heading. Export a PNG, an A4 PDF, or print.

What a hand is

A hand is the saved record of the handwriting of one person. It holds letter images, pens, slant, and spacing. It does not hold the photos. You can keep more than one hand in this browser, and you can move a hand with a .inkpack file.

A missing character is built from the other letters and marked as generated, or the page stops and names the character. An AI-assisted note is stored in every PNG and PDF. A small footer shows the same note and is on by default.

What it is not for

Do not submit a page where a person is required to write by hand. Do not use it for signatures or identity documents. The terms and privacy pages say the same thing.

Questions and answers

These answers are the same text search engines and answer engines read from this page.

What is Inkcadence?

Inkcadence is a free browser app that learns the handwriting of one person and writes new pages in that hand. You supply the words. The app supplies the letters.

Does Inkcadence write the words?

No. You type every word. Inkcadence only draws those words in the learned hand.

Who is Inkcadence for?

People who want notes, letters, or journal pages in their own handwriting. It is not for signatures, identity documents, or pages that must be written by hand.

How does a hand get learned?

You confirm the writing is yours, fill a letter sheet, or copy five known lines if you have no printer, and you may add up to eight old pages. The app reads the letters on this device.

What is a letter sheet?

A two-page sheet you print, with a box for each character. You write one character in each box and photograph both pages, with all four corner marks in the frame.

What if I have no printer?

Copy five known lines onto any paper and photograph that page. Each letter is read from its place in the line.

What is a hand?

A hand is everything Inkcadence knows about the handwriting of one person: the letter images, the pens, the slant, and the spacing. Photos are not kept in the saved hand.

Do my photos leave this device?

No. Photos are read in the browser. They are not uploaded. There is no account and no server.

Where is my hand saved?

In this browser, in IndexedDB. You can export a .inkpack file and import it in another browser. The file does not contain the photos.

What if a character was never written?

Inkcadence builds it from the other letters in that hand and marks it as generated. You can accept it or replace it by writing that character on a fill-in sheet. A character that cannot be built stops the page and names it.

What does the AI-assisted note mean?

Every PNG and PDF carries a note that the page was written with AI assistance. A small footer on the page says the same thing. The footer is on by default and you can turn it off. The note in the file stays.

What can I export?

A PNG of each page, packed as one ZIP, a multi-page A4 PDF, or a print. The PDF page size is A4 portrait.

Is there a price or an account?

No. The app is free, it has no login, and it does not ask for a payment.

Can I submit a page where handwriting by hand is required?

No. Do not submit Inkcadence output where a person is required to write the page by hand, and do not use it for signatures or identity documents.

Which browsers work?

Current Chrome, Edge, Firefox, and Safari. The app needs canvas and a way to save data in the browser. A phone can photograph the sheet. A computer can upload those photos.

Can I use it offline?

After the first visit has loaded the app, writing does not need a network.

Is the source available?

Yes. The license is MIT. The repository is github.com/mafzalkalwardev/inkcadence.

Where is the live site?

The site is on GitHub Pages at https://mafzalkalwardev.github.io/inkcadence/ and the app is at https://mafzalkalwardev.github.io/inkcadence/app/.
